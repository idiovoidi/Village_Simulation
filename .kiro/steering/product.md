# Product Overview

A web-based 3D village simulation showcasing intelligent agent behaviors, environmental systems, and physics interactions. Built with Babylon.js and Havok Physics, the simulation features multiple AI agent types (fish, birds, dogs, zombies, boats, villagers) operating within a dynamic environment with procedural village generation, water physics, cloud systems, and a day/night cycle.

The primary interaction model is observation-focused, allowing users to watch autonomous agents interact with their environment and each other. The simulation uses a flexible level system to configure different scenarios (Village, Coastal, Wilderness, etc.) with varying combinations of agents and environmental features.

## Key Features

- Multiple distinct AI agent types with unique behaviors and navigation patterns
- Dynamic environmental systems (water simulation, clouds, procedural village/road generation)
- Havok-powered physics for realistic interactions
- Configurable level system for different simulation scenarios
- Day/night cycle with world clock
- Performance optimization (LOD, instancing, hardware scaling)
