# Agent Visuals

This directory contains visual specifications for all agent types in the 3D Village Simulation.

## Contents

- [villager-models.md](villager-models.md) - Villager model specifications and animations
  - Model hierarchy and geometry
  - Materials and color palettes
  - Animation definitions (idle, walk, work, greet)
  
- [zombie-sprites.md](zombie-sprites.md) - Zombie visual specifications
  - Detailed model structure with articulated limbs
  - Sickly skin and tattered clothing materials
  - Procedural shambling animation
  - Attack and suspicious animations
  
- [wildlife-models.md](wildlife-models.md) - Fish, bird, dog, boat model specifications
  - Fish: Simple box geometry with tail animation
  - Bird: Wing flapping and tail movement
  - Dog: Four-legged model with walking animation
  - Boat: Hull, mast, and sail structure
