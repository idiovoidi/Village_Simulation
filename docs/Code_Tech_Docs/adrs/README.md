# Architecture Decision Records

This directory contains ADRs documenting key architectural decisions and their rationale.

## Contents

- `001-ecs-pattern.md` - ECS pattern selection decision
- `002-event-bus-semantics.md` - Event bus semantics decision
- `003-modular-monolith.md` - Modular monolith architecture decision
- `004-state-machine-approach.md` - State machine approach decision

## ADR Template

Each ADR follows this structure:
- Status (Proposed | Accepted | Deprecated | Superseded)
- Context
- Options Considered
- Decision
- Rationale
- Consequences
